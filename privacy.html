Privacy Policy

Winston Gmail Manager · Last updated: October 23, 2026

Who uses this application

This is a private tool used only by its owner to manage his own Gmail account. It is not offered to the public and does not access any other person's Google account.

What Google data it accesses

With the owner's consent, the application requests only these Gmail permissions:

  • gmail.modify – read, search, label, archive and move messages to Trash (not permanent deletion)
  • gmail.compose – create and edit drafts, and send mail
  • gmail.settings.basic – manage labels and filters

It does not request full mailbox access, forwarding or delegation settings, or contacts.

How the data is used

  • Message content is processed to summarize, classify and draft replies for the owner.
  • To do this, relevant message content is sent to Anthropic's Claude API. Anthropic processes it under its commercial terms.
  • Summaries and an action log are stored on the owner's own computer.
  • Sending mail, deleting drafts or filters, and bulk actions run only after the owner confirms them.

Storage and security

The OAuth token is stored only on the owner's computer, with access restricted to the owner's account. It is never shared, published or sent to the AI model.

Sharing

Google user data is not sold, not used for advertising, and not shared with anyone other than the AI processing described above.

Limited Use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account page under Security → Third-party apps with account access.
